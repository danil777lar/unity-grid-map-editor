# Larje Map Editor

`com.larje.mapeditor`: a grid-based level editor. Paint surface, wall and prefab tile layers in the Scene view and bake them into meshes with colliders.

## Install

UPM cannot resolve git dependencies, so add UniTask, core and this package to `Packages/manifest.json`:

```json
"com.cysharp.unitask": "https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask#2.5.10",
"com.larje.core": "https://github.com/danil777lar/unity-gameplay-core-services.git",
"com.larje.mapeditor": "https://github.com/danil777lar/unity-grid-map-editor.git"
```

## Usage

1. Add a `Map` component to a GameObject.
2. In the inspector, add layers:
   - **Surface** (`MapLayerFaceMeshPlane`): a merged plane mesh with a material.
   - **Wall** (`MapLayerEdgeMeshWall`): walls along grid edges, built from one or more `SubwallConfig` assets for sections, materials and vertex colors. A wall layer without subwall configs is skipped.
   - **Tile** (`MapLayerFacePrefabTile`): spawns a `TilePrefab` per cell, with random model variants. It can bake everything into one mesh per material with `Mesh.CombineMeshes`; no third-party baker is needed.
3. Select a layer, pick the Map Editor tool in the Scene view toolbar and paint with Brush, Eraser or Rect.
4. Press **Build**. Generated meshes are saved to `Assets/3D/Autogenerated/Meshes`. Child maps (for example, created with **Detach**) are rebuilt recursively.

## Paint from code

```csharp
MapLayerFaceMeshPlane floor = map.AddLayer<MapLayerFaceMeshPlane>("Floor");
floor.AddTiles(floor.GetTilesInRect(new Vector2(0, 0), new Vector2(9, 5), true));
floor.RemoveTile(MapLayerFace.Cell(4, 2));

MapLayerEdgeMeshWall walls = map.AddLayer<MapLayerEdgeMeshWall>("Walls");
walls.AddTiles(walls.GetTilesInRect(new Vector2(0, 0), new Vector2(9, 5), false));
walls.AddTiles(walls.GetTilesOnLine(new Vector2Int(5, 0), new Vector2Int(5, 4)));

map.Build();
```

Surface and tile layers store unit cells `(x,y)->(x+1,y+1)`. Wall layers store unit edges between grid points, and an edge equals its reverse.

## Unity CLI commands

With `com.unity.pipeline` in the project, a running editor exposes these commands to the [Unity CLI](https://docs.unity.com/en-us/unity-cli) (`unity command <group> <name>`):

| Command | Purpose |
|---|---|
| `larje.map describe [--target --skip_tiles]` | Describe a map in the open scenes: layers, types, bounds, tiles, child maps |
| `larje.map paint --layer <name> (--ops '<json array>' \| --file <ops.json>) [--create_as --build --target]` | Apply `rect` / `cells` / `line` / `tiles` / `clear` operations (each can set `erase: true`), create the layer if needed and optionally build (undo-able). Save the scene afterwards with `unity command scene save` |
